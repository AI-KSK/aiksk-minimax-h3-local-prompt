# 导演台提示词逻辑：给普通创作者看的版本

## 一句话

**先认人，再认图；先讲清楚发生什么，再讲怎么拍；上一幕最后的动作，要能接上下一幕第一个动作。**

## 1. Picture 是照片，Subject 是“身份证”

你上传三张图，导演台能直接知道的是：

```text
<Picture 1>
<Picture 2>
<Picture 3>
```

它们只是三份素材。

如果三张图里都是同一个女主，你要进一步告诉 H3：

```text
<Subject 1> is the same woman established by <Picture 1>, <Picture 2>, and <Picture 3>.
```

平民化解释：

- Picture：档案里的照片编号
- Subject：给角色办身份证

所以三张照片可以共同证明“这是同一个人”。

## 2. 为什么还要继续写 Picture

如果某张图不仅提供长相，还负责告诉模型“这一幕应该长什么样”，那它还有分镜作用。

例如：

- Picture 1 = 摸野猪的开场构图
- Picture 2 = 被追的中段构图
- Picture 3 = 骑野猪的高潮构图

于是：

- Subject 管“谁不能变”
- Picture 管“这一幕参考哪张图”

## 3. summary 是 10 秒故事梗概

`summary` 不是细节，而是先告诉模型整部短片到底在干嘛。

比如：

> 女主先摸野猪，然后被野猪追，最后抓住链条借力骑上野猪，一起冲向远方。

## 4. retention_analysis 是“哪些东西不能乱改”

女主如果必须保持同一个人：`fully_preserved`。

野猪皇冠、獠牙、饰品必须保持：`fully_preserved`。

如果场景本来就要从草地变市场再变旷野，就不要强行 fully preserved；具体地点允许变化。

## 5. detailed_description 才是真正的导演分镜

真正写片子时，不应该只写：

```text
摸猪。
被猪追。
骑猪。
```

因为这只是三件事，不是一个连续故事。

应该写成：

```text
摸猪
→ 女主逗它
→ 野猪抬头、喷鼻、身体前倾
→ 切到街道时追逐已经开始
→ 女主回头
→ 她伸手抓链条
→ 切到旷野时这个抓取动作继续完成
→ 借力上猪
→ 骑猪飞奔
```

这就是“因果桥”。

## 6. 10 秒如何分

不要机械平均。按信息量分。

例如：

- 0–3.3s：摸猪 + 野猪被逗起劲
- 3.3–6.9s：追逐 + 女主决定抓链条
- 6.9–10s：上猪 + 骑猪冲出去

注意：最终写进 H3 的时间点要服从 ComfyUI/Director 实际有效时长，若帧数网格发生 snap，就以实际有效时长为准。

## 7. 为什么六段式有用

把它当剧组文件：

```text
subject_definitions = 演员/道具身份证
summary = 故事梗概
retention_analysis = 哪些东西不能变
detailed_description = 正式分镜脚本
overall_soundscape = 环境音和动作音
non_diegetic_music = 观众听见、角色听不见的配乐
```

## 8. 最后口诀

**文件不是角色。Picture 不是 Subject。**

**同一角色跨图，先建立 Subject。**

**图承担关键帧/构图作用，再单独追踪 Picture。**

**多镜头不是三张图轮播，而是一条动作链。**

**先做动作链，再写镜头，再写声音，最后编译六段式。**
