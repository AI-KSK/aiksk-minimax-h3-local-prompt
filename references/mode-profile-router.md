# 模式与档位路由

## 模式判定

### T2VA

用户没有提供图像、视频或音频参考，只要求从文本生成。

### I2VA

用户明确说“首帧”“从这张图开始”“让这张图动起来”。

### L2VA

用户明确说“尾帧”“最后落到这张图”“反推之前动作”。

### FL2VA

用户同时给起点和终点，要求中间连续变化。

### Ref2VA

素材用途不是简单首尾帧，而是身份、服装、风格、动作、镜头、场景、音色、节奏或音频复用。

## 档位判定

### Direct

满足多数条件时选择：

- 单镜头、简单动作。
- 官方 ComfyUI 模板演示。
- 用户要短、直接、可运行。
- 没有复杂对白和多参考关系。

### Enhanced

满足任一条件时优先：

- 用户明确要求官方结构、Context-IR风格或详细提示词。
- L2VA / FL2VA 需要准确落点。
- 多镜头时间线。
- 对白、唱歌、画外音、跨镜头台词。
- Ref2VA 多素材职责复杂。
- 需要结构化校验。

### Auto

先按任务复杂度选择。不要因为用户说“官方”就自动声称三段式是唯一官方运行格式；官方 ComfyUI 模板也使用自然语言直接提示词。
