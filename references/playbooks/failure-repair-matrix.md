# Failure Repair Matrix

| Failure | First repair | Second repair | Avoid |
|---|---|---|---|
| face drift | strengthen identity anchor | reduce style/action overload | adding unrelated detail |
| wrong outfit | explicit clothing lock | separate outfit reference label | vague “same clothes” only |
| weak motion | decompose action chain | simplify camera | more adjectives |
| camera chaos | one dominant move | fewer cuts | stacking orbit+zoom+pan |
| rushed dialogue | reduce visual load | align cut to pause | paraphrasing locked dialogue |
| wrong speaker | rebuild S-ID map | separate Audio ref from speaker | assigning S ID to audio asset alone |
| wrong BGM behavior | mark copy vs reference | separate soundscape/music | saying “same audio” ambiguously |
| product deformation | geometry lock | gentler perspective | transformation on product |
| FL2VA miss | emphasize intermediate path | single continuous shot | two static endpoint descriptions |
| edit changes too much | edit_lock profile | explicitly preserve unchanged source | rewriting whole scene |
