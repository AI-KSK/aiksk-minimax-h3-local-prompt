# AI-K SK 提示词模式

## 人物唱歌

```text
Identity and composition anchor → breathing and mouth motion → expressive facial change → restrained body movement → camera push-in → vocal + stage ambience → optional audience-only score.
```

不要只写“女人唱歌”。应至少明确：演唱方式、口型、呼吸、手势、镜头、舞台声音和是否有观众配乐。

## 角色探险

```text
Opening pose and environment → cautious forward movement → environmental response → discovery or confrontation → reaction → end pose.
```

## 产品展示

```text
Product anchor → light sweep → controlled rotation or camera orbit → one functional change → final hero composition.
```

## 首尾帧人物动作

先比较两帧差异：头部角度、眼神、肩膀、手臂、身体重心、衣料、背景、镜头距离。把差异拆成2–4个连续中间动作，不瞬移。

## 参考职责表达

```text
<Picture 1> provides identity and clothing.
<Video 1> provides body motion and timing only; do not copy its person or background.
<Audio 1> provides voice timbre and delivery only; do not copy the original words.
```

明确“保留什么、只迁移什么、不要复制什么”。
