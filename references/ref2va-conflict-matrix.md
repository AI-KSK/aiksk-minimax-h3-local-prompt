# Ref2VA 冲突与排除关系

| 组合 | 硬关系 | 风险 | 写法 |
|---|---|---|---|
| 视频＋同号视频音轨 | 合法配对 | 无 | 明确音轨copy/reference职责 |
| 视频音轨无同号视频 | 无效 | 官方实现不登记音频 | 改接独立音频口或补对应视频 |
| 视频无音轨 | 合法 | 生成声音可能与动作偏离 | 提示词描述目标声音或接独立音频 |
| 图片＋视频 | 合法 | 视频人物身份污染图片人物 | 视频限定为motion/camera only，并排除身份服装背景 |
| 视频音轨＋独立音频 | 合法 | 两者争夺人声/音乐控制 | 分层：动作声 vs 目标音色；写清Audio编号 |
| 两段动作相反的视频 | 合法但冲突 | 运动平均、失败或混合 | 分配不同Shot或不同身体阶段 |
| 两个音频都控制同一说话者音色 | 软冲突 | 音色混合 | 指定主参考与次参考，或只保留一个 |
| 同一音频重复接两个端口 | 源码可处理 | 重复条件和编号混乱 | 只接一次 |
| 纯独立音频 | 官方模型规格禁止 | 缺视觉输入 | 改用T2VA或增加图/视频 |
| R2V参考图充当首尾帧 | 不是同一机制 | 终点不严格 | 需要严格首尾帧时用FL2VA |
