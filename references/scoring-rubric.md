# v1.5 多参考盲评评分锚点

所有指标使用0–5分；硬失败单列，禁止用平均分掩盖。

| 分数 | 通用含义 |
|---:|---|
| 0 | 完全失败、目标关系不存在或严重相反 |
| 1 | 仅有零散迹象，基本不可用 |
| 2 | 部分完成，但偏差明显且不稳定 |
| 3 | 基本完成，可用但有明显缺陷 |
| 4 | 大部分准确，只有轻微问题 |
| 5 | 高度准确、稳定且无明显泄漏 |

## Ref2VA专项指标

- `label_accuracy`：输出是否符合Manifest所登记的素材标签关系。
- `role_isolation`：每份参考素材是否主要影响指定职责。
- `identity_consistency`：目标角色身份是否稳定。
- `motion_transfer`：参考视频动作与节奏是否被正确采用。
- `camera_transfer`：运镜、构图变化和切镜节奏是否被正确采用。
- `audio_source_accuracy`：配套音轨与独立音频是否未串号。
- `speaker_binding`：参考声音是否落到指定目标人物。
- `av_sync`：动作、对白和物理声音的时间关系。
- `attribute_leakage_control`：源视频人物、服装、背景、声音或文字是否被错误带入；5分表示无明显泄漏。
- `overall_quality`：在任务目标下的总体可用性。

## 硬失败

标签不存在、错声音绑定、目标身份被源视频人物替换、目标动作完全缺失、要求的音轨完全缺失、严重音画错位、输出损坏或不可播放。
